# Hệ thống Quản lý Thư viện Số (Lab 02 - Ứng dụng công cụ AI)

- **Sinh viên thực hiện:** Trần Thị Khánh Linh
- **MSSV:** 30214150211
- **Công cụ AI & Môi trường:** Antigravity IDE (Gemini 3.8 Flash), HTML5, TailwindCSS, JavaScript (LocalStorage)

## Cấu trúc thư mục
- `src/index.html`: Mã nguồn hoàn chỉnh của ứng dụng web và dữ liệu mẫu tích hợp sẵn.
- `BaoCao_Lab.pdf`: Báo cáo phân tích, thiết kế hệ thống và minh chứng triển khai.
- `README.md`: Hướng dẫn cài đặt và khởi chạy ứng dụng.

## Hướng dẫn cài đặt và khởi chạy
1. Giải nén file dự án hoặc clone repository về máy tính.
2. Truy cập vào thư mục `src/`.
3. Nhấp đúp chuột vào file `index.html` để mở trực tiếp trên trình duyệt web (Chrome, Microsoft Edge, Cốc Cốc...) mà không cần cài đặt thêm cơ sở dữ liệu hay thư viện bên ngoài.
4. Dữ liệu mẫu (5 đầu sách, 3 độc giả, 2 phiếu mượn) sẽ tự động khởi tạo ở lần chạy đầu tiên.
